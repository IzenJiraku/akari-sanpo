# Xのかわりに

x.com / twitter.com（mobile. などのサブドメインも）を開くと、
https://izenjiraku.github.io/akari-sanpo/ へ移る Chrome 拡張です。

## 入れかた

1. このフォルダ（extension）をパソコンに置く
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ

Edge・Brave など Chromium 系でも同じ手順で入ります（Edge は `edge://extensions`）。

## やめたいとき

`chrome://extensions` でオフにするか、削除します。

読み込むと「x.com と twitter.com のデータの読み取りと変更」の許可が表示されます。
ページを移しかえるために必要なもので、それ以外のサイトには何もしません。
